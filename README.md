# Computer-Architecture-Simulation-Projects

# Out-of-Order Superscalar Core Simulator:
Implemented a cycle-accurate out-of-order superscalar CPU simulator (RAT/ROB/RS, 2-wide) and matched reference CPI results within 0.01–0.3% across 16 configurations on bzip2, gcc, libquantum, and mcf traces.
Project link: https://drive.google.com/drive/folders/1wLt8rXbl6lIKZl8xO-YayUcLMAHg3YLf?usp=share_link

# Multi-level Cache and DRAM Simulator:
Implemented a timing based multi-level cache/DRAM simulator in C++ with dynamic way partitioning that reduced L2 read-miss rate by 4.8%, cut DRAM read delay by ~4.0%, and boosted IPC up to 4.2x across mixed workloads 
Project link: https://drive.google.com/drive/folders/1wLt8rXbl6lIKZl8xO-YayUcLMAHg3YLf?usp=share_link
